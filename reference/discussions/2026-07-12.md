# 2026-07-12 — Six-agent deep reflection on the memory pivot (synthesis)

Aden asked to send the whole ~1h Socratic dialogue (why the fast-weight memory can't work data-free, and whether real-video reconstruction + an "a-notre-sauce" adaptive Muon write is a way out) to agents. Launched 6: 4 Opus (novelty-adversary, mechanism-soundness, feasibility-recode, strategy-EV) + 2 Fable (strategic-judgment, wildcard-novel-angle).

## Unanimous conclusions

1. **The adaptive Muon write is DEAD as a novelty headline.** All three flavors are published:
   - surprise-gated write = Titans (2501.00663).
   - spectral selective renorm = VLA (2605.11196) + GPM/SGP (2103.09762) + the delta-rule's defining property; AND technically a trap — our `zeropower_via_newtonschulz5` deliberately does NOT expose the update's singular directions (produces US'V^T with S'~U(0.5,1.5)), so "keep novel singular directions" isn't even well-defined on our substrate without importing VLA's penalty matrix.
   - scene-aware decay = Echo-Forcing (2605.16003) "difference-aware memory decay", in our exact streaming-long-video task.
   => the write rule is at best one ablation row, never the contribution.

2. **Do NOT build the real-video reconstruction pipeline on spec.** Path A is preempted at the mechanism (VideoSSM 2512.04519, MemGen 2512.18741) AND at the solution (Memento "Reconstruct to Remember" 2606.14667, June 2026). A solo 4-GPU effort cannot win a monthly-publishing race. Feasibility says it's ~450 LoC and fits 4 GPUs — the constraint is "should", not "can", and the answer is no as a headline bet.

3. **Our only un-preempted asset = the diagnosis + audited negative (metric-integrity, Goodhart triad) + a re-ID/revisit benchmark.** This is the thesis spine.

## The important CORRECTION (mechanism agent, code in hand) — our slogan was TOO STRONG

"You cannot reward a long-range memory with a short-range judge" is only half true.
- CONFIRMED in code: `real_score` and `fake_score` are both bidirectional Wan called with only the current chunk + constant prompt + timestep — **no kv_cache, no sink** (model/base.py:36-39, model/dmd.py:84-120, model/streaming_training.py:1304-1308). The DMD chunk is a sliding ~21-latent-frame (~5s) window. So NO direct gradient for long-range, **text-under-specified instance** identity (the real re-ID gap).
- BUT two nuances that reshape the narrative:
  - **Text is a global anchor** (CFG on the constant prompt): category identity IS scored every chunk. Only text-under-specified attributes (exact face/instance) drift free. This SHARPENS the pivot: re-ID = exactly the text-under-specified component.
  - **A GLOBAL memory has a DMD-rewardable job even under a windowed teacher**: the memory state at i changes window-i plausibility, so DMD back-props into earlier writes that reduce error-accumulation/motion-death. **VideoSSM is a live counterexample**: global SSM memory, pure windowed DMD self-rollout, NO reconstruction, co-trained with the DiT, and it reduces drift. So the real reason OUR memory games = **frozen backbone + already-sufficient KV/sink (no marginal per-chunk job)**, NOT an absent gradient. They co-train; we freeze.
- Consequence: if we write paper B, state the PRECISE version ("instance identity is unsupervised by DMD AND our frozen setup denies the memory a stabilization job"), or a reviewer cites VideoSSM and sinks it.
- Also: reconstruction-on-real is NOT how the preempt papers balance losses. VideoSSM uses no reconstruction at all; MemGen puts the faithfulness/reconstruction pressure on the MEMORY module while the generator keeps its generative objective (decoupled, not a weighted sum); TTT-Video is multi-step (no few-step sharpness tension) = category mismatch. Reconstruction-on-real needs paired data + teacher-forcing + co-training.

## The genuinely NEW idea (Fable wildcard) — break the binary

The binary smuggled an assumption: supervision comes only from (i) hand-built rewards (gameable) or (ii) a dataset (preempted). The real distinction is **factorized vs non-factorized judges**. Our data-free judges were factorized (identity term + motion term, each with a degenerate optimum = freeze/flicker). Reconstruction works not "because data" but because a real trajectory is a **non-factorized witness** (one target specifying identity AND motion jointly, so freeze isn't optimal). Design rule: never reward properties, only match witnesses.

**You can manufacture non-factorized witnesses WITHOUT data, from the model itself, by giving a second copy privileged context.** => "Anchor Resurrection": self-generated A->B->A-revisit rollout; oracle branch re-splices subject-A's anchor KV at the revisit point (using AF's own Anchor-Memory KV-reorg + Tri-Region RoPE); student branch has A genuinely evicted (memory = the only path back); loss = match the oracle's denoised revisit latents + vanilla DMD. Data-free, non-factorized (immune to the triad by construction), and the memory's job is crisp: **hold more anchors than the sink can** (multi-entity / post-eviction revisit provably exceeds sink capacity). Closest neighbor = Context Forcing (2602.06028) but that needs a separately-pretrained long-context teacher + data; ours needs zero new teacher, zero data, frozen backbone + a KV splice. It also answers the mechanism agent's objection ("trained re-ID hits the same missing-objective wall"): the oracle IS the missing objective, fabricated data-free.

## First move (both strategy agents, resolved)

Opus-strategy wanted a 1-2 week reconstruction experiment as the gate; Fable-strategy wanted an inference-only re-ID probe. The mechanism correction + novelty + wildcard resolve in favor of Fable's ordering (cheaper, decides more, no pipeline):

**Inference-only splice/re-ID probe** (~days, 1 GPU, ZERO training): A->B->A, splice A's KV at revisit, measure ArcFace/DINO delta (SAM crops) vs no-splice. Triple duty: (a) B's spine figure (the re-ID gap measured cleanly), (b) the go/no-go gate for Anchor Resurrection (does the oracle actually re-ID? if the model ignores stale spliced KV, the idea dies in an afternoon = already a B result), (c) $0, no pipeline. Pre-register the decision rule AND a NULL prior (an untrained memory has no reason to re-ID; a positive is likely base+sink, not the fast weight, and must be dissected). One precondition: the switch-pipeline ttt_cache bypass fix for the adversary arms.

## Recommendation (my synthesis)
1. Bury the adaptive write as a headline (everywhere).
2. Start WRITING B now (it's ~90% run, 0% written, perishable): the PRECISE diagnosis + the audited Goodhart triad + the metric-integrity suite. The guaranteed thesis floor. Target TMLR / analysis-benchmark track (no novelty gate).
3. Run the inference-only splice/re-ID probe in parallel (1 GPU, days): B's spine AND the gate for the one positive bet.
4. Keep **Anchor Resurrection** as THE positive bet (NOT the reconstruction repro). If the probe says the oracle re-IDs -> code A->B->A + oracle-distillation (data-free, frozen backbone, reuses MAG + Muon write + dmd_switch + AF KV-reorg). If not -> the null strengthens B.

Not "A vs B". It's "B as the floor + a $0 probe that decides whether to attempt the only un-preempted A (Anchor Resurrection, not reconstruction)."
